## 支持平台

- macOS Apple Silicon
- Windows 10/11 x64

## 功能

- ChatGPT 网页 OAuth 登录
- Codex 网页 OAuth 登录
- 生成并复制固定的 `oneopenai_rt_...`
- 刷新 Access Token

## 使用

1. 下载并安装 OneOpenAI。
2. 选择 ChatGPT 或 Codex。
3. 在浏览器完成登录。
4. 回到 OneOpenAI 复制生成的凭证。
